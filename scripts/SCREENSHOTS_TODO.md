# Documentation screenshots — remaining work

The docs screenshots are regenerated by [`scripts/screenshots.mjs`](screenshots.mjs) (Playwright, light
theme, fixed historical seasons). **35 shots are automated — every app screenshot the docs reference
except the three credential-blocked ones below.** To capture/force a skipped shot:
`node scripts/screenshots.mjs <name>`.

Data-source convention: the **H-scoring / draft page uses 2024-25** (Giannis ranks top-6 there — he's
the punt exemplar the docs discuss); **auction & season use 2025-26** (Season needs it — its default
rosters are 2025-26 players).

Recently automated (verified against a live run): `mdraft` (pick controls + board via `#right-header`,
Nikola Jokic locked in as pick 1), `mauction` (same region in Auction Mode, Jokic to Team 1 for $70),
`moreinfo` (union capture of the drafters / picks-per-drafter cells + third-round-reversal toggle),
`hec2` (candidate table at Team 1's round-7 pick, built by extending the mid_draft board with five more
lock-in/autopilot cycles), `gteam` (team-statistics G-score table on the same round-7 board), and
`rosterjokic` (rosters-grid player search: double-click Team 2's first cell, type "Niko").
