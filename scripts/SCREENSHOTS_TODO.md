# Documentation screenshots — remaining work

The docs screenshots are regenerated by [`scripts/screenshots.mjs`](screenshots.mjs) (Playwright, light
theme, fixed historical seasons). **24 shots are automated.** This file tracks the ones that still need
work. To capture/force a skipped shot: `node scripts/screenshots.mjs <name>`.

Data-source convention: the **H-scoring / draft page uses 2024-25** (Giannis ranks top-6 there — he's
the punt exemplar the docs discuss); **auction & season use 2025-26** (Season needs it — its default
rosters are 2025-26 players).
